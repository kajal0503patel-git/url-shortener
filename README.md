# URL Shortener

A backend service that converts long URLs into short, shareable codes and redirects users to the original URL. Built to practice production-style backend patterns: caching, graceful degradation, and layered architecture.

## Features

- Create short URLs via a REST API
- Redirect short codes to their original URL (HTTP 302)
- Duplicate URLs return the same short code instead of creating a new one
- Redis caching (cache-aside pattern) for fast redirects
- Graceful fallback to MySQL if Redis is unavailable, so the app never goes down due to cache failure
- Thread-safe short code generation using Base62 encoding

## Tech Stack

- Java 21, Spring Boot 4
- Spring Data JPA + MySQL
- Spring Data Redis (Lettuce client)
- Docker Compose (MySQL + Redis)
- JUnit 5

## Architecture

Client -> Controller (UrlController / RedirectController) -> UrlService -> Redis (cache-aside, 1hr TTL) -> MySQL (UrlMappingRepository)

## Design Decisions

- Base62 encoding: Short codes are generated by encoding the database's auto-increment ID in base62 (0-9, a-z, A-Z). This keeps codes short and guarantees no collisions, since IDs are already unique.
- 302 redirect, not 301: A 301 (permanent redirect) gets cached by browsers, so repeat clicks never reach the server, making click analytics impossible to track. 302 (temporary) ensures every click hits the server.
- Cache-aside over write-through: The app checks Redis first, falls back to MySQL on a miss, then repopulates the cache. This keeps Redis optional rather than a hard dependency.
- Redis fallback with try-catch: If Redis is down, cache reads/writes fail silently and the app serves directly from MySQL. This was tested by stopping the Redis container while the app was running.
- Redis timeouts (2s connect/read): Without an explicit timeout, a downed Redis instance causes the client to hang for several seconds per request before failing over. Setting a short timeout makes the fallback fast.

## Running Locally

### Prerequisites

- Java 21
- Maven
- Docker Desktop

### Steps

1. Clone the repo
2. Copy .env.example to .env and fill in your own values
3. Run the whole stack (app, MySQL, Redis) with one command: docker compose up -d --build
4. The app runs on http://localhost:8080

## API Endpoints

### Create a short URL

POST /api/urls
Content-Type: application/json
Body: { "longUrl": "https://example.com" }
Response: { "shortCode": "1", "shortUrl": "http://localhost:8080/1" }

### Redirect

GET /{code}
Returns a 302 redirect to the original URL, or 404 if the code does not exist.

## Tests

Run with: .\mvnw test
Covers Base62 encoding, including concurrency safety, with JUnit 5.
